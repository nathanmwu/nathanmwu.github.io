01 — About Me

I'm a Computer Science graduate from UC Santa Cruz with a focus on building useful and interpretible AI systems. My work spans full-stack development, systems programming, and applied machine learning.

While at UCSC, I was part of my professor's teaching team, tutoring undergraduates in Artificial Intelligence and conducting research at the university’s Artificial Intelligence Explainability and Accountability Lab. My teaching experience spans all age groups, from kindergarteners to college seniors. I've taught programming and game design to K–8 students, and tutored high school math and computer science.

Outside of my technical and teaching experience, I enjoy practicing cardistry, origami, speedcubing, and rock climbing (both indoors and outdoors!).

02 — Projects

Math Tutor Agent

Adaptive K-12 math tutor built on a LangGraph agent loop that generates problems, verifies answers with SymPy symbolic math, and grounds explanations in a RAG knowledge base. Tracks per-student mastery and adapts difficulty — runs fully locally with Ollama.

Python LangGraph RAG SymPy ChromaDB Ollama

AI Network Recommendation Engine

LangChain agent powered by Google Gemini that intelligently routes natural-language queries across SQL, vector, and graph databases to recommend professional connections based on shared history and network proximity.

Python LangChain Gemini Neo4j Qdrant Streamlit

LLM Logic Reasoning

Explores LLM logical reasoning through the Logic-LM algorithm — translating natural language into Prolog, implementing backward chaining, and testing multi-layered inference with symbolic solvers to verify logical outputs.

Python Prolog LLM Logic AI

Mnemonica Trainer

Interactive web app for memorizing the Mnemonica card stack used in card magic. Features learn mode, three practice modes, card selection, and progress tracking.

JavaScript HTML/CSS Web App

Image Classifier (ConvNeXt)

Transfer learning pipeline for image classification using the ConvNeXt Large architecture in PyTorch. Demonstrates fine-tuning a state-of-the-art CNN on custom datasets with GPU acceleration.

Python PyTorch ConvNeXt Deep Learning

NLP Madlibs

Interactive word game that explores part of speech tagging and text selection using natural language processing techniques for automated Madlibs generation.

C++ NLP Text Generation
